# Техническое задание: Кирюша — AI-офис

## 1. Цель
Один бот MAX принимает запросы владельца, маршрутизирует их центральному координатору или одному из шести специализированных агентов. Система сохраняет идеи, задачи и запланированные напоминания.

## 2. Роли
- Кирюша: распределение и контроль задач, предложения планов.
- Аналитик конкурентов: исследовательские отчёты с источниками.
- VK SMM: контент-планы, черновики, публикации только после одобрения.
- Юрист: проекты документов, выделение рисков, обязательная проверка специалистом.
- IT: код/архитектура/тесты, без автоматического деплоя.
- Продавец: КП, CRM-черновики, без автоматической отправки клиентам.
- Репетитор: ученик и тренажёр преподавателя, отдельные учебные сессии.

## 3. Гибридная маршрутизация
`/agent <ключ>` закрепляет специалиста за диалогом; `/agent kiryusha` возвращает автоматическую маршрутизацию. В MVP автоматическая маршрутизация работает по ключевым словам; в следующих версиях — модель классификации с явным подтверждением неоднозначных назначений.

## 4. Сущности (MVP)
Conversation(owner_id, selected_agent)
Record(id, owner_id, kind, title, agent, status, due_at, delivered_at)
InboxEvent(event_id)
AuditLog(owner_id, agent, action, detail, created_at)

## 5. Нефункциональные требования
HTTPS/TLS, секрет webhook, allowlist MAX ID, отдельный API-ключ локального интерфейса, переменные окружения для секретов, отсутствие внешних действий без подтверждения, изоляция пользовательских записей, журнал действий, резервные копии. Для производства — PostgreSQL, queue/outbox, ACL и наблюдаемость.

## 6. Приёмочные сценарии
- Локально без токена MAX: `/idea`, `/task`, `/list`, `/done`, `/agent`, `/agents`.
- Изоляция двух владельцев: записи одного не видны другому.
- Защита API без ключа.
- MAX webhook отключен до настройки токена, секрет обязателен.
- После MAX интеграции: идемпотентная запись событий; напоминания владельцу.
- Отсутствие опасных автономных действий.

## 7. Границы версии 0.1
Уже реализовано ядро и демонстрационные агенты; AI-провайдер опционален. Межагентные зависимости, календарное планирование натуральным языком, реальные инструменты агентов и полноценный контроль доступа внедряются последовательно.
