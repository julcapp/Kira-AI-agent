# Расширение мастера анализа 1С: комплексная проверка
Решение пользователя 2026-11-22.
В список «Что хотите проверить?» добавить пятый вариант: **«Комплексная проверка — всё перечисленное выше»**.
Включает: (1) общее состояние бухгалтерского учёта, (2) дебиторская и кредиторская задолженность, (3) финансовые результаты, (4) поиск ошибок и расхождений.
Последовательный сбор файлов: сначала одна полная ОСВ за период; далее при необходимости баланс и отчёт о финансовых результатах, ОСВ по счетам 60/62/76, аналитика сч. 90/91/99, адресные карточки счетов. Не требовать весь набор сразу; избегать повторной загрузки уже полученных файлов.
Показывать покрытие проверок и ограничения, не объявлять «полную проверку» без достаточных файлов и без независимой оценки достоверности. Тарифные лимиты и квоты обработки применяются прозрачно.
Это спецификация, а не уже реализованная функция.
