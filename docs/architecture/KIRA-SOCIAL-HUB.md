# Kira Social Hub
Статус: архитектура утверждена пользователем 24.11.2026.
Единый модуль платформы Кирюша, без отдельного backend, CRM или постоянной ветки.
Каналы: VK, MAX, Telegram, YouTube, TikTok, Instagram, Дзен, Одноклассники, Rutube, Web, Email.
Контракт адаптера: connect, disconnect, health_check, get_capabilities, validate_content, publish, get_statistics, get_comments, get_status, refresh_token.
По умолчанию внешние операции отключены. Публикация требует разрешения, подтвержденной доступности официального API, проверки законодательства, согласования конкретной версии материала и прав организации. При отсутствии API — ручной экспорт черновика. Секреты вне репозитория. Изоляция организаций и аккаунтов, журналирование, идемпотентность, очередь и обработка ошибок. Никакой фиктивной статистики.
Этапы: контракт и тесты; реестр каналов; интерфейс управления; VK пилот; прочие адаптеры после проверки документации и доступов; аналитика.
