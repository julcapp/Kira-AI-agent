# Интеграция
Исполнитель: существующий sales, координатор: kiryusha. Использовать единую библиотеку, без нового бота, базы или API. Дополнительные навыки: квалификация, КП, возражения, переговоры, follow-up, удержание. CRM, аналитика конверсии, сохранение этапов по пользователю и организации требуют отдельных проверенных интеграций. Не считать их реализованными. Ручная отправка всегда за пользователем.
# Приемочные сценарии
- Нет данных: один блок вопросов.
- Нет кейсов: честный пилот.
- Нет цены: не называть цену.
- Нет подтверждения: не переходить на следующий этап.
- Холодный контакт: только подтвержденная персонализация.
- Просьба отправить: только черновик.
- Отсутствует история: запросить контекст.
